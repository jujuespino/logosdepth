Help improve LogosDepth (beta)

Optional and off by default. If you turn it on, the app sends anonymous usage events such as “started a verse” or “finished a review”, tied to a random ID kept only in this browser. It never sends what you type, which verses you choose, or your email. Turning it off deletes the ID and asks the server to erase what it received.
